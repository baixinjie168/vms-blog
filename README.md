# 白心解 · 知行录 (vms-blog)

> 实体书卷纸墨装帧质感 · 七维认知个人数字花园博客

依托 **Cloudflare Pages 一体化全栈** 运行：
- **核心框架**：Astro 5 + TypeScript + Tailwind CSS v4
- **边缘适配器**：`@astrojs/cloudflare`
- **部署配置**：`wrangler.jsonc`

## 本地开发与构建

```bash
# 安装依赖
npm install

# 启动本地开发服务
npm run dev

# 生产环境打包构建
npm run build

# 本地预览生产构建产物
npm run preview
```
